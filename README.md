# 📅 Event Management System (PoC)

Мінімально життєздатний продукт (PoC) системи управління подіями. Додаток дозволяє користувачам реєструватися, створювати власні події, а також переглядати та приєднуватися до подій інших учасників.

Проєкт розроблено як тестове завдання для стажування **Radency (Node.js & React)**.

---

## ✨ Основний функціонал

* **Автентифікація:** Реєстрація та логін користувачів (JWT токени).
* **Управління подіями:** Створення, редагування, перегляд та видалення подій.
* **Взаємодія:** Можливість приєднуватися до публічних подій та залишати їх.
* **Seeding:** Автоматичне наповнення бази даних тестовими користувачами та подіями при першому запуску.
* **Документація:** Автоматично згенерована документація API через Swagger.

## 🚀 Як запустити проєкт (Zero-Config)

Проєкт налаштовано для максимально швидкого старту. Усі змінні оточення (включно зі секретами бази даних та JWT) вже налаштовані в `docker-compose.yml` для цілей локального тестування. Вам **не потрібно** створювати файл `.env` вручну.

**Переконайтеся, що у вас встановлено та запущено [Docker Desktop](https://www.docker.com/products/docker-desktop/).**

1. Клонуйте репозиторій на свій комп'ютер:
   ```
   git clone <посилання-на-твій-репозиторій>
   cd <назва-папки-репозиторію>
Запустіть проєкт однією командою:


docker-compose up --build
(Перший запуск може зайняти кілька хвилин, оскільки Docker завантажує образи бази даних, Node.js та встановлює всі залежності).

🌍 Доступ до додатку
Після успішного запуску (коли в терміналі з'явиться Nest application successfully started), додаток буде доступний за такими адресами:

🎨 Frontend (React UI): http://localhost:5173

⚙️ Backend (API): http://localhost:3000

📖 Swagger Документація: http://localhost:3000/api/docs

👤 Тестові дані (Seeding)
Для зручності перевірки, при першому запуску база даних автоматично наповнюється тестовими даними. Ви можете одразу увійти в систему, використовуючи ці акаунти:

Акаунт 1 (Організатор подій):

Email: alice@example.com

Пароль: password123

Акаунт 2 (Учасник):

Email: bob@example.com

Пароль: password123

🛑 Як зупинити проєкт
Щоб зупинити контейнери, натисніть Ctrl + C у терміналі, або виконайте команду:


docker-compose down
(Якщо ви хочете повністю очистити базу даних перед наступним запуском, додайте прапорець -v: docker-compose down -v).
