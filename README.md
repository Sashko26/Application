# Event Management System (PoC)

Мінімально життєздатний продукт (PoC) системи управління подіями. Розроблено за допомогою React (Vite), NestJS та PostgreSQL.

## 🚀 Як запустити проєкт (однією командою)

Переконайтеся, що у вас встановлено **Docker** та **Docker Compose**.

1. Клонуйте репозиторій.
2. Відкрийте термінал у кореневій папці проєкту.
3. Виконайте команду:
   ```bash
   docker-compose up --build
